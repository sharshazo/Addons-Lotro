====================================================================
LOTRO_Quest_Assistant - Documentacion del addon
====================================================================

QUE ES
------
Es el addon propio desarrollado en este proyecto: un asistente de
misiones (quests) en espanol para LOTRO. Su objetivo central es
mostrar el nombre, descripcion, objetivos y ubicacion de las
misiones ACTIVAS del jugador traducidos al espanol (segun un
diccionario/base de datos maestro propio), junto con herramientas de
seguimiento visual con estetica de "libro" (pergamino/tapa de cuero,
igual que la UI nativa del juego).

Carpeta principal: LOTRO_Quest_Assistant/
Punto de entrada: Main.lua
Archivos de plugin: LOTRO_Quest_Assistant.plugin y QuestSync.plugin
(el addon expone funcionalidad como dos plugins relacionados: el
asistente de misiones propiamente dicho y el sincronizador de
misiones/rastreador).

MODULOS / CARPETAS Y PARA QUE SIRVE CADA UNO
---------------------------------------------

Core/  (logica central, sin interfaz)
  - QuestManager.lua: administra el estado general de las misiones
    activas del jugador.
  - QuestResolver.lua / QuestLocResolver.lua: resuelven que mision
    real del juego corresponde a que entrada de la base de datos
    propia (por id/nombre) y su ubicacion.
  - QuestEventParser.lua: interpreta los eventos que dispara el
    cliente del juego relacionados con misiones (aceptar, avanzar,
    completar, etc.).
  - QuestStateManager.lua: persiste el estado de seguimiento de
    misiones entre sesiones (por ejemplo, que mision esta "oculta" o
    fijada en el tracker).
  - GatherEventParser.lua: interpreta eventos de recoleccion
    (materiales/nodos) relacionados con misiones de recoleccion.
  - NavigationParser.lua: logica de apoyo para navegacion hacia
    objetivos de mision.
  - MoorMapZoneResolver.lua: resuelve la zona actual del jugador
    usando la misma logica de referencia que el addon MoorMap, para
    poder cruzar datos de zona con la base de datos propia.
  - FoundStateManager.lua: estado de elementos "encontrados"
    (cofres, nodos, etc.) ya visitados por el jugador.
  - EventBus.lua: sistema interno de eventos/mensajes para
    comunicar los distintos modulos de Core entre si sin acoplarlos
    directamente.
  - LanguageSettings.lua: alterna el idioma de visualizacion del
    addon (ES/EN) de forma independiente al idioma del cliente del
    juego; se guarda con Turbine.PluginData (persistente entre
    sesiones). Por defecto: espanol.

Data/  (bases de datos propias, sin logica)
  - QuestDatabase*.lua (varios archivos numerados): base de datos de
    misiones (ids, nombres, metadatos), dividida en partes por
    tamano.
  - QuestLocalization_Full.lua / QuestLocalization_Lv1_10.lua:
    traducciones completas de texto de misiones al espanol.
  - QuestLocES.lua / QuestLocES_Full.lua: ubicaciones de misiones en
    espanol.
  - QuestNameESIndex*.lua / QuestNameIndex.lua: indices para buscar
    rapido el nombre en espanol de una mision a partir de su id (o
    viceversa).
  - QuestObjectiveESIndex*.lua: traduccion en espanol de los textos
    de objetivos de cada mision.
  - QuestLocCoords.lua / QuestStagesCoords.lua / QuestZoneIndex.lua /
    ZoneMapIndex.lua: coordenadas de mapa y zona asociadas a cada
    mision/etapa de mision, usadas para mostrar ubicacion.
  - ChestsDB.lua / GatherNodesDB.lua / FarmingDB.lua: bases de datos
    de cofres y nodos de recoleccion (materiales/farmeo).
  - ThreatsDB.lua: base de datos de amenazas/enemigos relevantes.
  - LostLoreDB.lua: base de datos de objetos de "lore perdido".
  - MoorMapZones.lua / MoorMapZonesES.lua: nombres de zona en
    ingles/espanol tomados como referencia del addon MoorMap.
  - WarbandMapBounds.lua: limites de mapa usados para ubicar
    contenido de "warbands".

Persistence/
  - GatherPointsStore.lua: guarda de forma persistente los puntos de
    recoleccion (nodos) que el jugador ya encontro o marco.

Legacy/
  Adaptadores que traducen datos/formatos de otros addons de
  referencia (MoorMap) al formato interno propio, y una version
  anterior de la base de datos de misiones/objetivos mantenida por
  compatibilidad (LocationAdapter.lua, MoorMapAdapter.lua,
  MoorMapCustomAnnotations.lua, QuestDatabase.lua,
  QuestObjectiveIndex.lua, WaypointAdapter.lua).

UI/  (todas las ventanas visibles del addon, estilo "libro/pergamino")
  - QuestTrackerHUD.lua: el HUD flotante que muestra en pantalla la
    lista de misiones activas seguidas por el jugador, con fondo de
    pergamino, boton para ir al objetivo ("Ir") y boton para ocultar
    cada mision del tracker.
  - QuestBookWindow.lua: ventana tipo "libro de misiones" con el
    detalle completo de una mision (titulo, texto de dialogo/NPC,
    objetivos) en espanol.
  - QuestSyncWindow.lua: ventana de sincronizacion/gestion de
    misiones (buscar, filtrar, ver el listado completo).
  - QuestSyncLauncher.lua: el icono flotante que abre las ventanas
    principales del addon (libro de misiones y lupa/buscador),
    equivalente al "launcher" de otros addons grandes.
  - QuestInfoTooltip.lua: tooltip emergente con informacion resumida
    de una mision al pasar el mouse.
  - GatherWindow.lua: ventana de ayuda de recoleccion (muestra nodos
    de materiales cercanos/relevantes); establece el patron de
    "viewport + recorte + arrastrar para desplazar" usado como base
    para mostrar imagenes grandes dentro de una ventana de tamano
    limitado.
  - GatherCaptureButton.lua / GatherNodeTooltip.lua: boton para
    marcar un nodo de recoleccion como encontrado, y su tooltip
    asociado.
  - ChestsWindow.lua: ventana de ayuda para cofres cercanos/relevantes.
  - NavigationPanel.lua: panel de navegacion hacia el objetivo de
    mision seleccionado.
  - MEMBookStyle.lua: modulo de estilo compartido por TODAS las
    ventanas de arriba (fuentes del cliente del juego, colores de
    texto tipo "libro antiguo", botones con icono en 3 estados). Es
    lo que le da a todo el addon una identidad visual consistente,
    a tono con la interfaz nativa de LOTRO.

Resources/
  Imagenes/texturas propias del addon (fondos de pergamino, iconos
  de botones, etc.).

Utils/
  Funciones auxiliares varias usadas por el resto del addon.

FUNCIONES PRINCIPALES (resumen para el usuario final)
--------------------------------------------------------
1. Traduce al espanol el nombre, texto de dialogo y objetivos de las
   misiones activas, usando una base de datos maestra propia (no
   traduccion automatica en vivo).
2. Muestra un HUD flotante con las misiones activas seguidas, cada
   una con boton para ir al objetivo y boton para ocultarla.
3. Ventana de "libro de mision" con el detalle completo de una
   mision seleccionada.
4. Buscador/sincronizador de misiones (QuestSyncWindow) para ver o
   filtrar el listado completo.
5. Ayudas de recoleccion: muestra nodos de materiales y cofres
   cercanos/relevantes, con posibilidad de marcarlos como
   encontrados.
6. Todo con estetica visual "de libro" (pergamino, tinta, tipografia
   del propio juego) consistente entre todas sus ventanas.

NOTA HISTORICA
---------------
En este proyecto se llego a desarrollar (y luego se elimino por
pedido explicito) un "Atlas de la Tierra Media" navegable dentro de
este addon: un mapa grande con zoom/desplazamiento e iconos por
zona con nombre/nivel/DLC. Se descarto porque el motor del juego
tiene un limite de memoria de textura por ventana demasiado bajo
para una imagen de mapa completa a buena resolucion. No forma parte
del addon actual.
